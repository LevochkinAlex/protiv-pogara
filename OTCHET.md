## 3. Структура сайта

### Страницы

- `/` — главная
- `/uslugi` — каталог услуг (11 услуг)
- `/uslugi/[slug]` — карточка услуги
- `/blog` — список статей (9 постов)
- `/blog/[slug]` — статья
- `/about` — о компании
- `/kontakty` — контакты и форма
- `/privacy` — политика конфиденциальности
- `/feedback` — отдельная страница формы
- `/404` (not-found) — кастомная страница ошибки

### API

- `POST /api/chat` — чат с OpenRouter AI
- `POST /api/chat/lead` — отправка лида из чата (email + Telegram)
- `POST /api/feedback` — форма обратной связи (email + Telegram)

### Статические файлы

- `/robots.txt`
- `/sitemap.xml`
- `/llms.txt`
- `/og.png`
- `/favicon.ico`, `/icon.png`, `/apple-icon.png`, `/Icon.png`
- `/site.webmanifest`

## 5. Переменные окружения (для продакшена)

| Переменная | Назначение |
|------------|------------|
| `OPENROUTER_API_KEY` | Чат-бот (обязательно) |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS` | Отправка заявок на почту |
| `MAIL_FROM`, `MAIL_TO` | Отправитель и получатель (alipov@inpb.pro) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` | Уведомления в Telegram |
| `NEXT_PUBLIC_APP_URL` | https://inpb.pro |
