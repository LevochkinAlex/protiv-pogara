# Институт НПБ - Многостраничный сайт с блогом и чат-ботом

Профессиональный сайт для компании в сфере противопожарной безопасности с полным функционалом для управления услугами, блога и интерактивного общения с клиентами.

## Функциональность

### 📄 Страницы сайта
- **Главная страница** - Привлекательный лендинг с полным набором блоков
  - Hero секция с призывом к действию
  - Список услуг с картинками и описаниями
  - Преимущества компании
  - Прайс-лист
  - Превью последних статей блога
  - CTA секция

- **Страница услуг** (`/uslugi`) - Каталог всех предложений
- **Карточка услуги** (`/uslugi/[slug]`) - Детальная информация о каждой услуге
- **Блог** (`/blog`) - Список статей с фильтрацией и поиском
- **Статья блога** (`/blog/[slug]`) - Полный текст статьи с рекомендациями похожих постов
- **Контакты** (`/kontakty`) - Форма обратной связи, реквизиты компании
- **О нас** (`/about`) - История и ценности компании

### 🤖 Чат-бот виджет
- Плавающий виджет в углу экрана
- Интеграция с OpenRouter AI (использует Llama 3.1)
- Интеллектуальные ответы на вопросы о пожарной безопасности
- Автоматический сбор данных клиента через tool calling
- Сохранение заявок через форму обратной связи
- Адаптивный дизайн для мобильных и десктопа

### 📧 Форма обратной связи
- Отправка заявок на email (через SMTP)
- Отправка уведомлений в Telegram бот
- Валидация всех полей
- Обратная связь пользователю при успешной отправке

### 📰 Блог
- SEO-оптимизированные статьи
- Категоризация постов
- Рекомендации похожих статей
- Метаданные для социальных сетей

## Технологический стек

- **Next.js 16** - React фреймворк с SSR
- **TypeScript** - Типизированный JavaScript
- **Tailwind CSS v4** - Утилитарный фреймворк для стилей
- **shadcn/ui** - Готовые компоненты UI
- **AI SDK 6** - Интеграция с AI моделями
- **OpenRouter** - API для доступа к различным LLM моделям
- **Nodemailer** - Отправка email уведомлений
- **Lucide React** - Иконки

## Переменные окружения

Создайте файл `.env.local` с следующими переменными:

```bash
# Обязательные для чат-бота
OPENROUTER_API_KEY=sk-or-v1-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# SMTP Mail.ru — для отправки заявок на email
SMTP_HOST=smtp.mail.ru
SMTP_PORT=465
SMTP_USER=alipov@inpb.pro
SMTP_PASS=ваш-пароль
MAIL_FROM=alipov@inpb.pro
MAIL_TO=alipov@inpb.pro

# Опционально: для отправки в Telegram
TELEGRAM_BOT_TOKEN=your-bot-token
TELEGRAM_CHAT_ID=your-chat-id

# Для production
NEXT_PUBLIC_APP_URL=https://inpb.pro
```

### Получение API ключей

**OpenRouter API Key:**
1. Перейдите на https://openrouter.ai
2. Зарегистрируйтесь или войдите
3. Откройте Settings → API Keys
4. Скопируйте ваш API key

**SMTP Mail.ru:**
1. Используйте пароль от почты alipov@inpb.pro (или App Password, если включена 2FA)
2. Укажите в SMTP_PASS

**Telegram Bot (опционально):**
1. Напишите @BotFather в Telegram
2. Создайте нового бота через `/newbot`
3. Получите BOT_TOKEN
4. Узнайте свой CHAT_ID через @userinfobot

## Установка и запуск

1. **Установите зависимости:**
```bash
npm install
# или
pnpm install
```

2. **Создайте файл `.env.local` с переменными окружения** (см. раздел выше)

3. **Запустите сервер разработки:**
```bash
npm run dev
# или
pnpm dev
```

4. **Откройте браузер:**
```
http://localhost:3000
```

## Кастомизация

### Изменение услуг
Отредактируйте файл `/lib/services-data.ts` и добавьте/измените услуги.

### Изменение статей блога
Отредактируйте файл `/lib/blog-data.ts` и добавьте новые статьи.

### Изменение цветов и стилей
Отредактируйте файл `/app/globals.css` и измените CSS переменные:
- `--primary` - основной цвет
- `--background` - фон
- `--foreground` - текст

### Изменение текстов на чат-боте
Отредактируйте файл `/app/api/chat/route.ts` и измените `systemPrompt`.
